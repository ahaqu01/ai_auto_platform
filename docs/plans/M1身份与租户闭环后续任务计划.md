# M1 身份与租户闭环后续任务计划

> Owner：交付负责人
> 版本：1.0
> 状态：CURRENT
> 前置：M1-01 Keycloak Compose 与 Realm IaC

## 执行顺序

1. `M1-02` BFF 登录/退出与管理台会话：Authorization Code + PKCE、服务端会话、HttpOnly Cookie、CSRF/Origin、刷新/吊销和浏览器 E2E。
2. `M1-03` CurrentUser 并发同步：PostgreSQL 原子 upsert，20 个并发首次请求不重复用户。
3. `M1-04` DTO、错误与契约基线：extra forbid，401/403/404/409、WWW-Authenticate 和 OpenAPI 固定。
4. `M1-05` 企业成员邀请与 RBAC：Owner/Admin/Member 权限矩阵。
5. `M1-06` 最后 Owner 并发保护：降级/移除不产生无 Owner 企业。
6. `M1-07` 项目生命周期：CRUD、归档、恢复、成员、分页、乐观锁。
7. `M1-08` 审计、幂等与 Outbox：关键写操作同事务，重放不重复。
8. `M1-09` 租户纵深防御：RLS、连接池上下文清理、跨企业读写矩阵。
9. `M1-10` Web 企业/项目闭环：登录、组织切换、成员和项目管理。

## 每包门禁

每个工作包独立执行：验收标准 → 红灯 → 最小实现 → API/PostgreSQL/Web/E2E → 安全复核 → Staging → 提交和 implemented 标签。不得将本地测试直接标记 ACCEPTED。

## 当前外部阻塞

Git remote、受保护 PR、CODEOWNERS 和连续三次远端 CI 仍为 `BLOCKED_EXTERNAL`；不得因此跳过本地及 Staging 门禁。
