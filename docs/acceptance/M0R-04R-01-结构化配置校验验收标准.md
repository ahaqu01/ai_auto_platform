# M0R-04R-01 结构化配置校验验收标准

> Status: READY
> Baseline: `4be82f7`
> Risk source: 严格评审 P1-02

## 验收标准

| ID | 标准 |
|---|---|
| SCFG-01 | DATABASE_URL 仅允许 postgresql+psycopg，必须有 username、password、host、port、database |
| SCFG-02 | REDIS_URL 仅允许 redis/rediss，必须有 host、port，路径只能是单个数字 DB |
| SCFG-03 | TEMPORAL_ADDRESS 必须为无 scheme、无路径/凭证/查询的 host:port |
| SCFG-04 | KEYCLOAK_ISSUER 必须为 HTTPS、有效 host，路径为 /realms/<realm>，无 query/fragment/userinfo |
| SCFG-05 | OSS public endpoint 必须 HTTPS；internal endpoint 允许 HTTP/HTTPS；二者必须有 host 且无业务路径、query、fragment、userinfo |
| SCFG-06 | 非法端口、空 hostname、错误 scheme 和畸形 URL 全部在启动阶段拒绝 |
| SCFG-07 | 错误只列字段名，不回显完整配置或密码 |
| SCFG-08 | local/test 保持当前开发兼容性；结构化强校验仅作用于 staging/production |
| SCFG-09 | 原有 localhost、HTTPS 和本地默认凭证保护继续有效 |
| SCFG-10 | 专项和全量回归通过，提交和版本标签完整 |

## 范围边界

本任务不实现 DNS 解析、link-local/metadata 地址阻断或 Settings 冻结；这些属于 M0R-04R-02。
