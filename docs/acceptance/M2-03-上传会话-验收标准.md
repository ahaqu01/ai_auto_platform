# M2-03 上传会话验收标准

- 状态：CURRENT
- Owner：QA / 安全 / 平台 API
- 日期：2026-09-02

## 强制标准

1. 新增可迁移、可降级的 upload_sessions 表，状态、大小、SHA-256、Key 和配额字段有数据库约束。
2. object_key 只能由服务端生成，满足 `v1/o/{32 hex}`，全局唯一且不含用户输入或租户标识。
3. 创建仅允许组织管理员或项目 ADMIN/ENGINEER；跨租户/非成员隐藏资源，VIEWER 返回 403。
4. 授权先于归档检查；归档项目写入返回 `409 PROJECT_ARCHIVED`。
5. 0 字节和 20 GiB+1 拒绝；SHA-256 必须为 64 位小写十六进制；展示名/类型拒绝控制字符。
6. 组织级并发会话与预留容量在组织行锁下检查，取消和过期释放预留。
7. 创建与取消要求 Idempotency-Key；相同请求重放原响应，不同请求返回冲突。
8. 创建、取消/过期与审计、Outbox、幂等结果同事务提交。
9. upload_sessions 启用并 FORCE RLS，受限 platform_runtime 具有最小 CRUD 权限。
10. GET、取消和惰性过期不泄露 object_key、storage_upload_id 或凭据。
11. 不调用对象存储，不提前实现 Multipart/完成校验，不创建 AVAILABLE 资产。
12. SQLite API 专项、PostgreSQL 迁移/RLS、OpenAPI、完整回归和 CI 通过。
13. 输出 `M2-03开发文档.md` 和独立验收记录。

任一强制项失败则 M2-03 不通过，禁止进入 M2-04。
