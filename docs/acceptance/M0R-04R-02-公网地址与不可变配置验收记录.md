## 实现与测试映射

- Settings 构造期：OIDC issuer 与 OSS public endpoint 拒绝非全局 IP 字面量和已知 metadata 主机名，但不发起外部 DNS 查询。
- public/internal 分离：OSS internal endpoint 保持允许 RFC1918 私网地址，既有回环、结构与协议限制保留。
- 运行时解析：出站前解析主机，空结果、非法结果或任一非全局/组播结果均拒绝。
- 重定向：每次跳转基于源 URL 规范化目标，并在跟随前重新执行 HTTPS、主机和 DNS 地址策略。
- OIDC：默认 JWKS 客户端替换为 `SafePyJWKClient`，初始请求与重定向均接入同一策略；策略失败统一映射为不包含目标值的连接错误。
- 不可变配置：Pydantic Settings 启用 `frozen=True`，构造完成后字段赋值失败。

## 人工边界复核

- 域名在 Settings 构造期不解析，避免启动依赖 DNS；安全校验发生在实际 JWKS 出站前。
- DNS 结果逐项校验，而不是只检查第一条记录。
- 重定向不能从 HTTPS 降级至 HTTP，也不能跳转到敏感地址。
- 当前做法仍存在 DNS 校验与底层连接之间的 rebinding/TOCTOU 窗口。平台尚无通用 URL 抓取能力；未来若新增高风险任意 URL 访问，应改为固定已验证解析结果连接或统一受控出站代理。
- OSS 尚未实现 SDK 出站链路，本任务只提供可复用策略，未虚构“OSS 请求已受保护”的结论。
