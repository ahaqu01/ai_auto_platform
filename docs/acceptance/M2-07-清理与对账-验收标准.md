# M2-07 清理与对账验收标准

> 日期：2026-09-15  
> 结论门槛：所有强制项通过，GitHub baseline / PostgreSQL / security 均成功。

## 功能标准

1. 到期且仍活动的上传会话转为 EXPIRED、释放配额，并补偿中止遗留 Multipart。
2. DELETING 资产的对象删除成功或对象已不存在时转为 DELETED，并写入删除时间。
3. AVAILABLE 资产只有在存储明确 NOT_FOUND 时转为 FAILED；暂时错误不得误判。
4. 孤儿扫描只允许固定前缀与合法 opaque Key，保护窗口内、数据库仍引用或格式非法的对象不得删除；删除前必须二次查库。
5. 单轮每类工作有 1～1000 的批量上限。

## 可靠性与安全标准

1. 对象存储 I/O 不在长数据库事务中执行。
2. 删除和中止的 NOT_FOUND 作为幂等成功；其他失败保留待处理状态并指数退避。
3. 数据库仅记录标准错误码，不记录 Key、Upload ID、签名 URL、凭据或 SDK 原始异常。
4. 状态变化与 SYSTEM 审计、Outbox 同事务提交；孤儿删除也有审计证据。
5. 迁移可升级/回退，约束清理次数非负，不削弱现有租户 RLS。
