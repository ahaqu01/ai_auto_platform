# M0R-07 运行可靠性验收标准

> Owner：QA 负责人
> 状态：CURRENT
> 版本：1.1

1. `/health/live` 仅证明 API 进程存活，不访问外部依赖。
2. `/health/ready` 至少探测 PostgreSQL；依赖可用返回 200，失败返回 503 且不泄露异常细节。
3. API 容器健康检查使用 readiness，而不是 liveness。
4. 所有 Compose 服务使用有界 `json-file` 日志，`max-size=10m`、`max-file=5`。
5. 长运行服务使用 `restart: unless-stopped`，一次性迁移服务使用 `restart: no`。
6. 执行 `docker compose restart api` 后，readiness 在 30 秒内恢复。
7. API 回归、部署静态契约、Compose 配置、文档检查、差异和敏感信息扫描通过。
