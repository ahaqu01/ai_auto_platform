## 功能证据

- 项目成员可游标分页读取非删除资产并读取详情；公开 DTO 不含对象 Key、Bucket 别名、Upload ID 或凭据。
- 只有 AVAILABLE 资产可签发 60～3600 秒短期下载 URL；隔离资产拒绝下载。
- 下载名移除路径和双引号，并返回 RFC 5987 Content-Disposition 建议值。
- 跨租户/非成员资产访问返回 404；归档项目允许读取但拒绝删除。
- 删除要求 Idempotency-Key 和匹配 If-Match，仅切换到 DELETING，并在同事务写审计与 Outbox。
- DELETING/DELETED 资产立即从列表、详情和下载路径隐藏；物理删除留给 M2-07。
