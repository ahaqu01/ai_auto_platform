# M2-06 资产访问与授权验收标准

> 状态：ACTIVE  
> 日期：2026-09-11

## API 与授权

- 项目成员可分页读取本项目非删除资产；跨租户和非成员返回 404。
- 资产详情返回版本 ETag，且不公开对象 Key、Bucket 别名、Upload ID 或凭据。
- 只有 AVAILABLE 资产可获得下载 URL；其他状态必须拒绝。
- 下载 TTL 限制为 60～3600 秒，默认 600 秒；下载文件名消除路径和响应头注入风险。
- 归档项目允许读取，但删除请求返回 `PROJECT_ARCHIVED`。

## 删除

- 删除需要写角色、合法 Idempotency-Key 和匹配的 If-Match。
- 删除只进入 DELETING，不在请求事务内直接删除对象。
- 删除状态、审计和 Outbox 同事务；幂等重放不重复产生事件。
- DELETING/DELETED 资产不出现在列表、详情或下载路径中。
