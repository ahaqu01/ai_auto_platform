# M1-07 项目完整生命周期验收标准

> Owner：平台工程 / QA
> 日期：2026-08-27
> 状态：PROPOSED

## 范围

项目 CRUD、归档与恢复、项目成员和角色、游标分页、版本与 `If-Match` 乐观锁。

## 验收标准

1. 企业 Owner/Admin 可创建项目；项目 code 企业内唯一，不同企业可复用。
2. 创建者自动成为项目 ADMIN；普通企业成员只能看到已加入的项目，跨企业及未授权项目返回 404。
3. 项目 ADMIN 以及企业 Owner/Admin 可添加、改角色、移除项目成员；只能添加本企业成员。
4. 项目角色为 ADMIN/ENGINEER/VIEWER；非项目管理员不能管理成员。
5. 列表 `limit` 默认 20、最大 100，使用不暴露数据库结构的 opaque cursor，翻页无重复无遗漏。
6. 读取和写入返回 ETag；更新、归档、恢复和删除必须带 `If-Match: "<version>"`。
7. 同一版本的并发更新严格只能成功一个，失败方返回 412 `VERSION_MISMATCH`。
8. 归档后仍可读取；恢复后回到 ACTIVE；删除采用软删除并对后续读取隐藏。
9. 移出企业后，即使项目成员行仍存在，也立即失去项目访问。
10. Alembic 升降级、OpenAPI、本地 CI、真实 PostgreSQL 与 Demo 验收通过。
11. 形成独立提交和标签，工作树干净；M1-08/M1-09 仍为进入资产/任务域前强制门禁。
