# M1-CR-04 归档项目语义验收记录

- 状态：ACCEPTED_DECISION
- 日期：2026-09-01
- 决策依据：ADR-0005
- 范围：产品语义、API 错误码、M2 测试矩阵

## 验收标准

1. 明确归档后成员管理、元数据修改和业务内容写入是否允许。
2. 明确恢复后成员与权限是否保留。
3. 固定归档冲突的 HTTP 状态、错误码及授权检查顺序。
4. 给出覆盖读取、恢复、成员、元数据、并发、幂等和 M2 资产写入的测试矩阵。
5. 不在产品决策之前贸然扩大代码变更。

## 验收结果

| 检查项 | 结果 | 证据 |
|---|---|---|
| 归档后允许动作 | PASS | 读取、恢复、受控删除 |
| 归档后禁止动作 | PASS | 内容、元数据和成员写入 |
| 恢复语义 | PASS | 成员关系和权限原样保留 |
| API 冲突语义 | PASS | `409 PROJECT_ARCHIVED` |
| 信息隐藏 | PASS | 授权检查先于归档冲突判断 |
| 测试矩阵 | PASS | ADR-0005“验收测试矩阵” |
| 范围控制 | PASS | 本批次只固化决策，不添加 M2 占位代码 |

## 决策

M1-CR-04 的语义归档门禁通过。该结论仅表示决策和契约已经固化；现有 API 与 M2 资源 API 的实现必须分别通过对应自动化测试后，才能宣称行为实现完成。

## 后续强制项

- 项目元数据和成员写 API 按 ADR-0005 补齐归档状态测试。
- M2 资产与上传 API 从首个实现提交起执行 `409 PROJECT_ARCHIVED` 契约。
- 如需紧急成员移除，另立安全 ADR，不得修改本 ADR 形成隐式例外。
