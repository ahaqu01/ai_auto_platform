# M0D-01 本地阶段性演示部署验收标准

## 目标与边界

在本地服务器提供可重复部署、可从局域网浏览器访问的阶段性演示环境，用于查看当前 Web 首页和 API 运行状态。

本任务是内部演示部署，不是生产发布：仅开放局域网统一入口；数据库、缓存、对象存储和 API 不直接对局域网暴露；不宣称已关闭 REV-01 安全问题；不包含尚未实现的登录、标注、训练和模型部署功能。

## 验收环境

- 服务器：`192.168.1.129`
- 代码目录：`/home/diffgram/workspace/ai_auto_platform`
- 演示入口：`http://192.168.1.129:8080`
- 编排工具：Docker Compose
- 环境标识：`local`

## 验收标准

### AC-01 可重复部署

- 仓库包含独立的演示 Compose、镜像构建文件、反向代理配置和操作手册。
- `docker compose config` 通过；同一启动命令可重复执行。

### AC-02 数据库初始化

- PostgreSQL 健康后自动执行 Alembic `upgrade head`；迁移成功后 API 才启动。
- 数据使用命名卷持久化。

### AC-03 统一网页入口

- `/` 返回 200，并显示“AI 工程化与交付平台”。
- 同源 `/health/live` 返回 200 和 `status=ok`。
- `/docs` 可查看当前 API 文档。

### AC-04 最小暴露面

- 宿主机仅新增 `0.0.0.0:8080`；PostgreSQL、Redis、MinIO、API 不发布宿主机端口。
- 不修改路由器端口映射、公网安全组或公网 DNS。

### AC-05 可靠性和验证

- 服务具有重启策略；核心服务具有健康检查。
- 静态部署契约、前端测试与构建、API 测试、部署后 HTTP 冒烟测试全部通过。

### AC-06 版本管理

- 基线为 `6c99c858ca95f7feddda9938a2f46e4aee1ba74e`，任务使用独立提交。
- 验收通过后工作区干净，并创建注释标签 `m0d-01-local-demo-deployed`。
