# M1 总体验收标准

> Owner：产品 / 技术 / 安全 / QA
> 日期：2026-08-27
> 状态：CURRENT

## 强制标准

1. M1-01 至 M1-10 均有可追溯提交、标签、验收标准和验收记录。
2. 真实 Keycloak 用户完成 Authorization Code 登录、BFF Cookie、CSRF 写请求、组织切换和退出的浏览器到 API E2E。
3. 身份矩阵覆盖正常、过期、未来 iat、错误 iss/aud、未知 kid、Key 轮换、IdP 超时、刷新/吊销及邮箱/subject/issuer 组合。
4. 授权矩阵覆盖组织、成员、邀请、项目、项目成员；未登录、非成员、Member、Admin、Owner；允许、403、隐藏 404、冲突 409/412。
5. PostgreSQL 原子身份同步、最后 Owner 并发、If-Match、RLS 连接复用、审计/Outbox 回滚全部通过。
6. auth、authorization、tenant 模块聚合 branch coverage ≥90%，后端总体 branch coverage ≥80%。
7. Web 单测、类型检查、生产构建和关键交互 E2E 通过。
8. Critical/High SCA/SAST 为 0，或每项有批准且不影响认证/租户隔离的限时例外。
9. 当前 M1 构建在远程 CI 和 Staging 执行相同身份/授权矩阵并保存构建、镜像和数据库版本证据。
10. API、审计和数据库证据证明跨租户访问为 0。
11. OpenAPI、文档治理、迁移升降级、Demo/Staging readiness 和回滚证据通过。
12. 产品、技术、安全、QA 四方对同一证据包签字；全部 PASS 后才可创建 `m1-accepted` 并进入 M2。

任一强制标准为 FAIL 或 BLOCKED 时，总结论必须为 NOT ACCEPTED。
