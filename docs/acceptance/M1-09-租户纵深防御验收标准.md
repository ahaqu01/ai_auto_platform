# M1-09 租户纵深防御验收标准

> Owner：平台工程 / 安全 / QA
> 日期：2026-08-27
> 状态：IMPLEMENTED_LOCAL / PASSED_LOCAL

## 验收标准

1. ADR-0004 Accepted，明确应用 RBAC 与 PostgreSQL RLS 职责边界。
2. 迁移角色与 `platform_runtime` 运行角色分离；运行角色无 SUPERUSER、CREATEROLE、BYPASSRLS。
3. organizations、成员、邀请、projects、项目成员、audit 和 outbox 启用 RLS。
4. 无租户上下文时，运行角色对普通租户资源默认读取 0 行、写入被拒绝。
5. 企业 A 上下文不能读取、更新、删除或插入企业 B 的资源；反向同样成立。
6. 应用请求使用事务级 actor/organization context，禁止 Session 级 SET。
7. 同一物理连接依次处理企业 A、企业 B、无租户事务时变量和角色不污染。
8. commit、rollback 和请求异常后，`app.organization_id`、`app.actor_id` 与 LOCAL ROLE 恢复。
9. “我的企业列表”、企业创建和邀请接受通过明确窄化例外工作，不开放无租户表扫描。
10. 应用授权矩阵保持原有 403/404 语义，RLS 不替代动作级 RBAC。
11. Alembic 升降级、OpenAPI、本地 CI、真实 PostgreSQL 和 Demo 验收通过。
12. 形成独立提交和标签，工作树干净；通过后才解除进入资产/任务域的 M1-08/M1-09 前置阻断。
