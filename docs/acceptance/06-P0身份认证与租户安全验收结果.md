## 5. 本切片实现范围

- 仅允许 RS256 的 OIDC JWT 验证器。
- 校验签名、过期时间、Issuer、Audience、Subject。
- JWKS 公钥获取与缓存。
- Bearer Token 解析。
- CurrentUser 依赖。
- OIDC 用户本地同步和资料更新。
- 企业和项目 API 使用 CurrentUser。
- 删除客户端身份查询参数。
- OIDC 未配置时返回稳定 401，不产生 500。
