# M2-02 对象存储适配端口验收标准

- 状态：CURRENT
- Owner：QA / 安全 / 平台 API
- 日期：2026-09-02

## 强制标准

1. 领域层只依赖 ObjectStoragePort，不依赖厂商 SDK。
2. MinIO 和阿里云 OSS 复用同一 S3 兼容语义，同时校验各自 provider 配置。
3. Multipart 初始化、分片签名、完成、取消、Head、下载签名和删除均有端口契约。
4. 厂商错误归一化，原始 SDK 异常不越过 gateway。
5. 仅临时错误和超时重试，重试有次数上限和指数退避。
6. 每个网络操作有超时，并支持调用前及退避期间取消。
7. Key、Upload ID、预签名 URL、AccessKey、Secret 和原始异常不得进入日志。
8. part number 限制为 1～10,000，非法请求不触达 gateway。
9. 不引入未满足运行时 SSRF 门禁的 SDK/HTTP 客户端。
10. 旧阻断状态与测试原子更新，不能虚假宣称真实 OSS/MinIO 网络通过。
11. 相关单测、完整 API/Web 回归、文档检查、静态检查和 CI 通过。
12. 输出同名开发文档及独立验收记录。

任何强制项失败则 M2-02 不通过，禁止进入 M2-03。
